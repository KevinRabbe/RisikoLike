# ATLAS // FRONT — Audio & License Record

## M14 implementation

The current build uses named `AudioManager` events and procedural fallback tones generated by Godot's `AudioStreamGenerator`. This keeps UI feedback, error feedback, turn feedback, combat feedback, card feedback, victory feedback, and the optional low-volume menu ambience functional without shipping third-party recordings.

The only runtime controls are Master, Music, and SFX. They are persisted through `SettingsManager` and applied to the dedicated `Master`, `Music`, and `SFX` buses from `default_bus_layout.tres`.

## Asset policy

No third-party audio file or font is bundled by M14. When production music or recorded SFX are added, each asset must be listed here with source, author, license, attribution requirements, and redistribution permission before it enters a release package.

The procedural fallback is project-owned code and has no external asset attribution requirement beyond the Godot runtime license already used by the project.
